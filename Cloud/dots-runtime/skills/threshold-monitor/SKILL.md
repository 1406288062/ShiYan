# 阈值监控提醒

## 每个阈值一条记录
- 记下：监控的确切对象（代码、网址、商品）、阈值、方向（高于/低于）、检查间隔、取数方法，写进任务目录的 `monitors.json`。
- 新建前先看已有记录，同一个阈值不要建第二个监控。
- 用户设了多个阈值时，一个触发后只停那一个，其余继续，除非用户说全部停。
- 用 finish_run 的 status=continue 和 wake_after_seconds 实现定期检查；告诉用户检查间隔，并说明两次检查之间发生的穿越会在下一次检查时才发现，不是实时。

## 查准对象
- 只查用户说的那个对象，不要用相关的期货、基金或别的指数代替。
- 报数时说明是盘中、延迟还是收盘价，以及取数时间。
- 判断穿越前再取一次数确认，避免一次错误或过期读数误报。
- 每个阈值只提醒一次（notify=true），之后在 monitors.json 标记已触发，除非用户要求重新设置。

## 替换前先核实
- 判断某个监控“没在运行”之前，先看它的记录和最近几次读数。
- 发现重复的监控就删掉重复的、保留原来的，并确认每个阈值只剩一个。
